# Agronegocios Coronado — Frontend

Interfaz React + Vite para la gestión administrativa de AGRONEGOCIOS CORONADO S.A.C.

## Arranque

```bash
npm install
npm run dev
```

Usa un `.env` local (no se sube al repositorio) con `VITE_API_URL=/api`.

La app queda en `http://localhost:5173` y usa el proxy `/api` hacia Nest (`http://localhost:3000`).

Usuario seed: `admin@agronegocioscoronado.com` / `Coronado2026!`
